# QQSG Helper · QQ三国 多开辅助

Windows 桌面工具（Java / Swing）。基于**后台消息 + 内置 OCR 认字**驱动多个游戏窗口，
支持**最多 5 开**，5 个号可**后台并发**跑任务。

---

## 快速开始（下载即用）

1. 下载本仓库（`Code → Download ZIP`），**完整解压**到任意目录
2. 双击 **`Start.bat`** —— 会**自动请求管理员权限**（必须，否则按键发不进游戏）
3. 在界面里点 **刷新** → 选中游戏窗口 → **添加控制窗口**
4. 点对应任务按钮执行；再点一次同一按钮可中止

> **不需要安装 Java** —— 本包已自带精简运行时 `jre/`，启动器会优先进它。
>
> 解压后请**保持目录结构**：`Start.bat`、`jre/`、`target/` 必须在同一层。
>
> 必须以管理员身份运行。游戏客户端是高完整性进程，未提权时 Windows 的 UIPI 会
> 拦掉发过去的按键和窗口消息。

## 功能

| 按钮 | 说明 |
| --- | --- |
| **一键日常** | 工资 → 军团 → 霸王城，串起来跑 |
| 军团任务 | 初级军团任务，三层对话 + 收尾门禁（做满 5 次自动识别） |
| 霸王城 | 静修流程，13 步 OCR 认字点选项 |
| 工资 | 领取工资流程 |
| 孝廉 | 「推举孝廉」答题，本地题库模糊匹配（查不到才走 DeepSeek） |
| 打老鼠 | 太仓尉任务 |
| 抢线 | 自动抢指定线路 |
| 集体召唤 | 组队 + 集体召唤（图标模板匹配） |
| 组队 | 组队流程 |

每个受控窗口都有独立的 **启动 / 停止 / 后台 / 移除**。

## 环境要求

- **Windows 10 / 11**（依赖 Win32 API：EnumWindows / PrintWindow / PostMessage / SendInput）
- **Java 11+** —— 仅从源码构建时需要；**直接运行用随包的 `jre/` 即可**
- **中文 Windows**：内置 OCR 直接调用系统自带的 `zh-Hans-CN` 识别引擎
  （通过 PowerShell 调 `Windows.Media.Ocr`），**不需要额外安装任何 OCR 模型**
- 游戏建议使用 **窗口模式**，分辨率与抓图基准一致时识别最稳

## 从源码构建

```bash
mvn clean package
```

产物：

```
target/helper-1.0-SNAPSHOT-jar-with-dependencies.jar   ← 含全部依赖，直接可运行
```

把该 jar 放到 `target/` 下，双击 `Start.bat` 即可。

## 常见问题

**Q: 双击 Start.bat 提示找不到 Java？**
说明 `jre/` 目录没解压全（或被杀软删了）。重新完整解压压缩包即可；
启动器还会自动依次尝试 `JAVA_HOME`、常见安装目录和 `PATH`。

**Q: 点了任务按钮没反应 / 角色不动？**
八成是没有管理员权限，或者游戏窗口没有在前台。用 `Start.bat` 启动（它会自动提权），
并在执行任务时**不要让游戏窗口失去焦点**。

**Q: 杀毒软件报毒？**
工具会对游戏窗口发送按键与窗口消息（属于自动化控制行为），
部分杀软会启发式拦截。如拦截请加白名单——本项目全部源码开源可自行审阅。

**Q: 识别不准？**
OCR 的稳定性与游戏窗口大小、画质设置有关，建议保持**固定分辨率**。
